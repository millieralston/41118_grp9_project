Usage

Training

Run training from the group project folder:

cd 41118_grp9_project
python train.py

Running the environment

Some modules provide simple demos. For example, to test the Husky environment (if a demo exists):

python husky_env.py

Notes

  • Check `checkpoints/` for saved models created by `train.py`.
  • TensorBoard logs (if present) are under `ppo_tensorboard/` or similar folders.
