TipBot AI Project

Hello everyone, we are Group 9. My name is Melroop with my teammates Millie and Eliza. Our AI in robotics project is called the TipBot.

Project summary

Our system is designed to simulate a reinforcement learning system, where two Husky bots are loaded within a PyBullet simulated environment to chase another Husky bot while simultaneously avoiding obstacles. The TipBot system trains a robotic UGV to follow and intercept ground targets.

Current progress

  • Environment built with two Husky robots initialized at random positions.
  • Random obstacles added with PyBullet and a boundary fence around the arena.
  • Runner robot uses a scripted evasion policy while the chaser is the training agent.
  • Reward functions implemented with dense and sparse components.

Reward function

  • +200 for catching the runner
  • −0.8 × distance per step to encourage closing the gap
  • −5.0 obstacle/wall proximity penalty
  • −5.0 stuck penalty for no movement

Challenges

  • Version conflicts across group members created inconsistent PyBullet behavior and camera output.
  • We updated the code to avoid assumptions about returned data formats.
  • Training requires a dedicated GPU for CNN image processing instead of CPU.
  • Observation design is hard: enough useful input without overwhelming the agent.
  • The first trial produced a stationary chaser, showing reward and action scaling need tuning.

Technical inputs

  • Observation: 64×64×3 RGB camera image
  • Camera FOV: 60°
  • Projection near/far clip: 0.1 / 100.0
  • Action: 2 continuous controls [linear_velocity, angular_velocity]
  • Scaled in env: linear = action[0] × 4.0, angular = action[1] × 2.0
  • PyBullet stepSimulation() per action step; demo uses 240 Hz render loop.
  • Training uses DIRECT mode for uncapped step rate.
  • Episode setup: 12 trees, 5 benches, random spawns inside ±10.

Training config

  • n_envs = 4
  • Policy: CnnPolicy
  • n_steps = 2048
  • batch_size = 128
  • gamma = 0.99
  • gae_@article{park2021nerfies author = {Park, Keunhong and Sinha, Utkarsh and Barron, Jonathan T. and Bouaziz, Sofien and Goldman, Dan B and Seitz, Steven M. and Martin-Brualla, Ricardo}, title = {Nerfies: Deformable Neural Radiance Fields}, journal = {ICCV}, year = {2021}, }lambda = 0.95
  • clip_range = 0.2
  • ent_coef = 0.01
  • vf_coef = 0.5
  • max_grad_norm = 0.5
  • Total timesteps = 200,000

Next steps

  • Improve the reward policy to encourage active pursuit and obstacle avoidance.
  • Upgrade the runner’s scripted movement.
  • Improve collision avoidance.
  • Complete the CNN-based policy.
