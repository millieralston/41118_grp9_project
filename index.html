TipBot

Group 9 AI robotics project with PyBullet Husky bots.

Melroop, Millie, and Eliza are building a reinforcement learning pursuit system for simulated Husky UGVs.

Explore the TipBot project

Project summary

TipBot simulates a reinforcement learning system where two Husky robots operate in a PyBullet environment. One robot plays the runner using a scripted policy, while the chaser robot is trained to pursue and intercept the runner while avoiding obstacles.

Current progress

  • Fully built PyBullet environment with two Husky robots and randomized spawn positions.
  • Random obstacle placement with 12 trees, 5 benches, and a perimeter fence.
  • Runner uses a scripted evasion policy while the chaser is the training agent.
  • Reward function implemented with catch reward, distance shaping, obstacle penalties, and stuck penalties.

Training details

  • Agent runs in a PyBullet DIRECT mode for fast training.
  • Action space uses continuous linear and angular velocity controls.
  • Observation includes a 64×64×3 RGB camera image from the chaser’s forward-facing view.
  • Training uses Stable Baselines3 PPO with a CNN policy planned for image-based learning.

Why TipBot?

The goal is to demonstrate how reinforcement learning, reward design, policy training, and CNN-based visual input can be combined in a robotics setting. Instead of hard-coded obstacle rules, the chaser will learn from raw camera input how to pursue the runner safely and efficiently.

Next steps

Model improvements

  • Refine the reward policy to encourage pursuit while avoiding obstacles.
  • Improve runner scripted movement to create a stronger training challenge.
  • Complete the CNN-based policy for camera image input.

Training & system

  • Use GPU training for CNNs rather than CPU.
  • Improve collision avoidance for both Husky robots.
  • Tune velocities and penalties to prevent tilting and stuck behavior.
